# Examples — Worked Campaigns

End-to-end, worked campaign examples that show how the **Get Elected** modules combine into a single coherent run for office. Each example is a complete package — strategy, compliance, fundraising, messaging, field, and a dated execution calendar — built for a specific (sometimes fictional) candidate, office, and election date.

> Examples use **fictional candidates** for concreteness but ground all law, dates, limits, and district data in **real, web-sourced facts**, verified on the date noted in each example. Each example flags exactly what is real vs. illustrative, applies the skill's nonpartisan and educational-disclaimer guardrails, and is for educational use — not legal advice.

## How to use an example

1. Start with the example's **`README.md`** — it sets the scenario, the real-vs-illustrative boundary, and the reading order.
2. Read the numbered files in order (campaign plan → compliance → fundraising → messaging → field → calendar → artifacts).
3. Treat every number as a **template to adapt**, and **re-verify all compliance facts** against the FEC and the relevant Secretary of State before relying on them — limits and deadlines change every cycle.
